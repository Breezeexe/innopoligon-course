# Основы тестирования на проникновение

Архив учебного курса с платформы [edu.innopoligon.ru](https://edu.innopoligon.ru). Материалы сохранены в Markdown с исходной структурой, таблицами, блоками кода и ссылками на источники. Практические задания вынесены в отдельные каталоги рядом с соответствующей теорией.

Курс предназначен для начинающих пентестеров, администраторов, разработчиков и специалистов по информационной безопасности. Он охватывает полный цикл тестирования на проникновение: согласование работ, разведку, поиск и подтверждение уязвимостей, получение доступа, пост-эксплуатацию, повышение привилегий, горизонтальное перемещение и подготовку отчёта.

## Что находится в репозитории

- 11 тематических разделов;
- 383 теоретических конспекта в исходном Markdown;
- 44 практических задания;
- ссылки на источники во всех теоретических материалах;
- 549 исходных ответов API для проверки полноты экспорта;
- скрипт для повторной выгрузки материалов;
- файл контрольных сумм SHA-256.

Финальный экзамен намеренно исключён из архива.

## Структура архива

```text
innopoligon-export/
├── 01-.../ — 11 разделов курса
│   ├── README.md — оглавление раздела
│   ├── theory/ — оригинальные Markdown-конспекты
│   └── practice/ — практические задания
├── .source/api/ — исходные JSON-ответы API
├── tools/export.mjs — скрипт повторного экспорта
├── manifest.json — состав и параметры выгрузки
├── EXPORT_REPORT.md — результаты проверки полноты
└── SHA256SUMS — контрольные суммы файлов
```

Для чтения откройте нужный раздел в таблице выше, затем выберите материал в его оглавлении. Теория хранится без преобразования текста. В практических заданиях сохранены вопросы, варианты ответа, метаданные и доступные вложения; ответы не запрашивались и не генерировались.
